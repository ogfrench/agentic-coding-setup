# Presentation craft skill evaluations

Routing and quality cases for four brand-neutral skills. The repository's `node --test` checks their structure and coverage, not real presentation quality.

The `deck-from-brief` and `approved-outline-to-deck` cases test creative autonomy: producing work without compulsory story interviews, alternate narratives or outline sign-off. The story and visual review cases check that action titles remain a useful default, evidence stays defensible and anti-pattern examples are judgment aids rather than bans.

Run live skill evaluations in a supported Claude Code host and compare actual behavior with a no-plugin baseline. Static grading definitions are not proof of runtime behavior. Use synthetic briefs; never publish client material.
