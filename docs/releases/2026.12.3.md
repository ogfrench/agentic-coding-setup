# Agentic Workflow 2026.12.3: mobile exploratory testing reference

This release adds a source-linked, optional mobile testing reference to the
canonical Test Strategy skill, distributed with both the Claude Code and ChatGPT
editions of `agentic-workflow`. The version continues the existing 2026.12
release line.

## Changes

- Point to [mobile-agent-testers](https://github.com/pierridotite/mobile-agent-testers)
  as an example of parallel iOS and Android persona-driven exploratory testing.
- Clarify that AI findings require screenshot inspection and reproduction;
  confirmed failures should become deterministic regression tests.
- Keep adoption opt-in. Review third-party code, secrets and test data,
  GitHub Actions runner use and model costs before executing the external workflow.
- Add DUNE and README guidance, without incorporating upstream code or changing
  the central repository's CI gates, tool permissions or default installations.
- Preserve the `agentic-workflow` plugin name and existing skill counts
  (24 Claude; 28 ChatGPT). Rolling learning draft PR #113 remains separate.

## Verification and acceptance boundaries

- Release only a reviewed `main` SHA with green exact-head CI and the existing
  immutable GitHub release workflow; validate both archives and SHA-256 checksums.
- This source change does not run mobile emulators, validate the third-party
  workflow in a real app, or demonstrate better defect detection. The external
  repository's published examples are illustrative, not our own test results.
- Publishing GitHub archives does not automatically update installed ChatGPT,
  Claude Code or downstream repository plugins. Host installation and live-task
  acceptance must be checked separately.
