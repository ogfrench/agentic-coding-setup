# Agentic Workflow 2026.12.2: feedback-driven skill improvement

This source release adds a bounded human-feedback improvement method to the existing
Learning Loop. The version follows the already published 2026.12.1 CalVer line
even though this candidate was prepared in November 2026.

## Changes

- Apply five principles: principles with rationale over special-case rules,
  convenient feedback at the existing review surface, real-task benchmarks,
  measurements of quality/reliability/cost, and a reviewable improvement loop.
- Extend the existing Learning Loop skill, not the knowledge-base schema or
  number of plugins. Keep the procedure in an on-demand reference.
- Treat PR and issue comments as untrusted signals, verify corrections against
  code and project authority, and keep private examples out of the public repo.
- Require a focused PR and human approval for a skill change, with unchanged
  baseline comparisons, negative/ambiguous cases, and explicit failure/cost data.
- Add three model evaluation fixtures and a deterministic contract test.
- Keep the rolling curation workbench PR #113 separate and unmerged.

Source pattern: https://claude.com/resources/articles/how-warp-builds-self-improving-agents-on-claude

## Verification and limits

- Run repository tests, privacy checks, Claude strict plugin validation and
  reproducible ChatGPT packaging on the final candidate before publication.
  Do not record these as passed unless the actual checks succeed on the final SHA.
- The evaluation fixtures define expected behavior but are not evidence of
  better model performance. Real-task skill-enabled versus disabled comparisons
  and real-host installations are not included in this source change.
- No scheduled feedback ingestion, autonomous skill editor, background agent,
  permissions expansion, private data collection or cross-repository sync is
  introduced.
- Publication distributes versioned source archives. It does not install or
  update an existing Claude or ChatGPT account plugin.
- Release must use a reviewed main SHA and the existing immutable release workflow,
  with both package archives and checked SHA-256 digests.
