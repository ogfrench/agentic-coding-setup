# Inactive Claude Approvals example

The adjacent example is not a live policy and is not installed or synchronized.
Its syntax follows [Claude Approvals](https://code.claude.com/docs/en/approvals)
as documented on 2026-11-25. It is a starting point only; review real repository
paths and requirements before enabling it. One seat can include the author;
two seats can require another person and can deadlock a solo maintainer.
Neither replaces independently enforced GitHub checks or explicit human
authorization. Observe mode may incur usage charges and can affect review
coverage. Activation, budget and enforcement require an owner decision.
